# LMM plugin icon

`icon.svg` extends the project-owned folded ribbon from the parent repository's
`.github/assets/logo-geometry.json` (schema `lmm-api.logo-geometry/2`). Its four
ribbon paths are unchanged; the code brackets distinguish the OpenCode/Magpie
plugin within the shared LMM plugin family. No third-party logo or font is used.

The source is a 256 × 256 SVG with a fixed dark tile and is included in the npm
package. `package.json` uses the same asset's HTTPS URL for Magpie's plugin icon.
